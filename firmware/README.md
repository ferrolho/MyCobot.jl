# ATOM firmware

- `atom_controller/`: the onboard 500 Hz player (installed on the ATOM).
- `atom_probe/`: passive diagnostic firmware.

The documentation is on the project site, section **Firmware**
(`website/src/content/docs/firmware/`): how the cores are used, the states and
LED signals, the protocol, and how to build, flash and update over WiFi.

WiFi credentials are not in the repository: see `firmware/build-flash.md` on the site.
